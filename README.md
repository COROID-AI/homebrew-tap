# CoRoid's Homebrew tap

```sh
brew install coroid-ai/tap/coroid-connector
```

The formula installs [@coroid/connector](https://www.npmjs.com/package/@coroid/connector),
built from [COROID-AI/coroid-connector](https://github.com/COROID-AI/coroid-connector).
`.github/workflows/update.yml` takes a new release into the formula only after
verifying that the package was built and attested by that repository's Release
workflow.
